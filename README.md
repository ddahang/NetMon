# 网络流量统计工具（NetMon）

一款纯本地的 Windows 网络流量统计小工具。统计本机每天的上传/下载流量，支持实时网速、近 30 天 / 当月每日流量图表、开机自启动、托盘驻留等功能。

**零依赖、单文件、不联网** —— 数据只存在本地，不上传任何信息。

> by:吾爱 dingqh

## 功能特性

- **每日流量统计**：自动记录每天的上传 / 下载 / 合计流量，历史数据长期保存
- **实时网速**：每秒刷新的实时上传 / 下载速度（独立配色）
- **图表**：近 30 天每日流量 / 当月每日流量（自动按月份天数生成横轴）切换，日期刻度只在 1/5/10/15/20/25/30 显示数字，其余为短竖线
- **图表悬停明细**：鼠标悬停柱状图可查看当天上传 / 下载明细
- **后台采集**：可一键安装系统计划任务（每分钟自动采样，无需程序保持运行），也可用程序内置兜底采集（程序运行期间每 10 秒采样）
- **卸载采集任务**：一键卸载计划任务，数据文件完整保留
- **开机自启动**：勾选即生效（用户级注册表，无需管理员），启动后最小化到托盘
- **托盘驻留**：关闭窗口 = 最小化到托盘，右键托盘图标「恢复窗口 / 退出」
- **单实例运行**：重复打开 exe 自动唤回已运行的窗口
- **DPI 自适应**：适配 100% / 125% / 150% 等屏幕缩放，高分屏界面清晰不发虚
- **自包含**：exe 放到任意目录即可运行，自动在所在目录创建 `data\` 数据文件夹

## 运行环境

- Windows 10 / 11
- 无需安装 .NET 或任何运行库（使用系统自带的 .NET Framework）

## 使用方法

1. 把 `NetMon.exe` 放到任意目录（或直接放桌面），双击运行
2. 点「安装后台采集任务」→ 系统每分钟自动在后台记录流量（关掉程序也在记录）
3. 需要的话勾选「开机自启动」，开机后自动缩到托盘后台统计
4. 随时打开窗口查看今日流量、实时网速和历史图表

## 编译方法

修改 `NetMon.cs` 源码后，右键"使用 PowerShell 运行" `build.ps1` 即可重新编译：

```
NetMon.cs（源代码）
    │  build.ps1 调用系统自带编译器 csc.exe
    ▼
NetMon.exe（可执行程序，内嵌 favicon.ico 图标）
```

- 编译器为 Windows 自带的 `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe`，无需安装任何东西
- `build.ps1` 会自动为源码补 UTF-8 BOM（防止 PowerShell 5.1 解析中文乱码）

## 工作原理

- Windows 网卡计数器是"自启动以来的累计值"，程序周期性采样做**差值累加**，按天归档到 `data\netmon.json`
- 重启 / 网卡重置 / 休眠唤醒均有校正逻辑：检测到计数器变小（系统重启）则重建基线，不丢不重
- 计划任务模式：系统每分钟运行 `NetMon.exe /sample`（隐藏模式：采样 → 写数据 → 退出，不弹窗口）
- 已知限制：采样粒度约 1 分钟，极短突发流量可能有小幅误差；按日汇总场景下可忽略

## 文件说明

| 文件 | 说明 |
|---|---|
| `NetMon.exe` | 成品程序（单文件） |
| `NetMon.cs` | 全部源代码（约 800 行 C# WinForms） |
| `build.ps1` | 一键编译脚本 |
| `favicon.ico` | 程序图标（构建时嵌入 exe） |
| `data/netmon.json` | 流量统计数据（运行时自动生成，已加入 .gitignore） |

## 数据格式

`data/netmon.json` 示例：

```json
{
  "last_sent": 123456789,
  "last_recv": 987654321,
  "last_ts": "2026-10-29 08:40",
  "daily": {
    "2026-10-28": { "up": 1048576, "down": 52428800 },
    "2026-10-29": { "up": 2097152, "down": 104857600 }
  }
}
```

- `up` / `down` 单位为字节
- 删除此文件即可清零重新统计
